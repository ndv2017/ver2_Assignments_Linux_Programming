# Linux Programming Assignments

This repository contains various assignments related to Linux programming, covering topics such as general C programming, file systems, processes, signals, multi-threading, sockets, inter-process communication (IPC), and basic kernel module development.

## Repository Structure

### [01__General_Topics](01__General_Topics/)
Create static lib and shared lib using Makefile 

### [02__File_system](02__File_system/)
File operations, including reading, writing, and retrieving file information.

### [03__Process](03__Process/)
Process creation, management, and handling using system calls like `fork()`.

### [04__Signal](04__Signal/)
Signal handling in Linux, including blocking and unblocking signals, and handling SIGINT.

### [05__Multi_Thread](05__Multi_Thread/)
Multi-threading assignments demonstrating thread creation, synchronization, and how to use Mutex and Condition variable.

### [06__Socket](06__Socket/)
Socket program covering TCP client-server communication.

### [07__Pipe_N_FIFO](07__Pipe_N_FIFO/)
Inter-process communication using anonymous pipes and named pipes (FIFO) with producer-consumer models.

### [08__Shared_Memory](08__Shared_Memory/)
Reader-writer implementation using shared memory for IPC.

### [09__Message_Queues](09__Message_Queues/)
Implementation of message queues using both POSIX and System V message queue mechanisms.

### [10__Semaphore](10__Semaphore/)
Semaphore-based synchronization using named and unnamed semaphores, and a producer-consumer example.

### [11__Kernel_Module_Basic](11__Kernel_Module_Basic/)
Basic Linux kernel module development, including writing a simple kernel module and interacting with it via a user-space application.
